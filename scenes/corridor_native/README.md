# 完整走廊 RGB-T 3DGS 飞行场景

巡航、右侧墙接触测试、展板示范和 OpenFly 导航的录像、位姿与航点见[本次飞行记录](../../outputs/corridor_native_flights/README.md)。

## 相机和重建

本场景使用用户指定的 `corridor_full_native_20261121_1645/base_30000`。两份 3DGS PLY 分别来自 `point_cloud_color/iteration_30000` 和 `point_cloud_thermal/iteration_30000`。场景目录中的模型、相机清单和训练最后一步的支架变换均为指向原资产的符号链接，源路径与 SHA-256 已记录。两组高斯保留各自的球谐外观。[资产清单](inputs/assets.json)

每个动力学步结束后，固定在机体上的相机随无人机的位置与姿态一起更新。渲染器把模拟器中的 RGB 相机转换回重建坐标，得到 `W_rgb`。热相机在该时刻的外参为 `W_thermal = T_rgb_to_thermal @ W_rgb`。两幅图按各自内参渲染，水平视场约为 RGB 65.34°、热相机 36.22°。热录像表示原生热图的伪彩亮度，训练数据未提供绝对温度。场景支持 `RigScene(..., render_thermal=False)` 单独渲染 RGB。[双相机实现](room.py) · [相机外参](inputs/rig.json) · [内参与图像来源](inputs/manifest.json)

在每个采集片段中取一个留出的相机位姿，合计五对。将其转换到模拟器世界，重新渲染，再与同一曝光对应的 320×240 原图比较。RGB 的整图相关系数在 0.926–0.987 之间，热图在 0.980–0.997 之间。五组相机位姿经坐标往返后，热相机矩阵各元素最大误差小于 `1e-14`。该检查覆盖训练视角附近的重投影，不能给未拍到的侧向视角赋予同等精度。[逐相机检查](inputs/registered_view_check.json)

## 米制坐标

以地面为 `Z=0`，`+X` 沿去程采集视线，`+Y` 指向去程左侧，偏航 0° 朝 `+X`。尺度来自源 RGB 深度先验中可分辨的地面与天花板，二者的拟合间距为 **0.53010 个 SfM 单位**。缺少现场标尺，取室内层高 **2.80 m**，得到 **5.28205 m/SfM 单位**。因此飞行距离、速度、机体净空均按该假定比例给出。坐标变换为 `p_sim = s · R · (p_source − origin)`。两个侧墙的平面法向确定长轴方向。[变换、拟合样本数与残差](inputs/frame.json)

## 碰撞与已观测空域

构建器读取 278 个 RGB 训练视角，将 320×240 的 SfM 对齐单目预测深度与 RGB 高斯渲染的深度、方差和不透明度对照。在斜视墙面或地板时，沿相机光轴的深度方差容易受入射角放大。构建器同时检验地面、顶面和两侧墙面与各像素射线的交点，只保留深度支持的局部表面。

- **碰撞表面**。按 4 cm 体素融合候选，同一候选需要在三个相距至少 0.25 m 的相机位置得到一致深度，若至少三个视角表明该处其实是自由空间则剔除。过滤孤立点后有 **169,348** 个表面点。模拟器以 0.60 × 0.60 × 0.12 m 的机体盒、每侧 0.05 m 安全余量执行转动和平移的扫掠接触检测。[碰撞点云](collision/rgb_surface_m.ply) · [检测实现](../../pointcloud.py)
- **已观测自由空间**。10 cm 体素中心需从三个相距至少 0.25 m 的机位观测到，并位于有依据的表面深度之前至少 0.16 m。先验较弱的像素还须满足高斯累积不透明度超过 0.99，并取保守的先验与渲染深度下界。最终 **368,060 / 1,204,500** 个格子可用，剩余格子是未知区域。普通巡航检查整个机身安全包络。碰撞测试允许有意接近已定位墙面，同时记录包络何时越过自由空间边缘及扫掠何时真正接触表面。[空域网格](collision/free_volume.npz) · [构建统计](collision/build.json)

碰撞几何依赖同一采集中的视觉重建，未测区、细小物体和其他方向的壁面仍可能有缺口。视频中接触发生在机体安全包络碰到通过多视角验证的表面点时。

场景已经含有可直接加载的表面点云和空域。要重建它们，在本项目根目录执行下列命令。它会更新本走廊的 `inputs/frame.json` 与 `collision/` 下的几何文件。[构建程序](prepare.py)

```bash
conda activate thermal_gaussian_5070
OPENBLAS_NUM_THREADS=1 OMP_NUM_THREADS=2 python -B -m scenes.corridor_native.prepare
```
